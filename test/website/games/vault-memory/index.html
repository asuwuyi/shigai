如何打開金庫？

符號＋兩位數字會逐組在中央放大、停留，再漸隱。全部播放完才開始倒數。

選擇符號後，直接按數字鍵盤輸入兩位數字，按確認或 Enter。可用退格或清除修正。答錯會提示，可在剩餘時間內修正；答對所有組數即可開啟金庫。

每關開啟金庫後，會展示隨機公開作品與其畫框；有多件可用作品時避免連續重複。切換分頁會自動暫停。記憶階段繼續時從當組重新展示。進度僅保留於本頁，重新整理即重置。
